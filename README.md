# MOVE-IIIa Sun Sensor

Firmware, wire protocol, and host tools for a **4-quadrant pinhole sun sensor**
built on a **TI MSP430i2041**. The sensor reads four photodiode quadrants with
the on-chip SD24 sigma-delta ADC, computes the **sun unit-vector on-chip**
(trig-free closed form), and serves it to a host as a **4-wire hardware-framed
SPI slave**.

## Repository layout

```
CCS Project using GUI Composer/   MSP430i2041 firmware (Code Composer Studio project)
  Source/                         application, GUI/SPI transport, MSP430 HAL
  Include/                        public headers (HAL.h is the stable contract)
  targetConfigs/                  CCS target (.ccxml)
  lnk_msp430i2041.cmd             linker command file
SUN_SENSOR_SPI_PROTOCOL.md        self-contained SPI wire-protocol spec (v2)
tools/                            host-side Python tools
  serial_log.py                   robust serial logger (owns the COM port)
  sun_sensor_viz.py               live 3D sun-vector visualizer
  serial_rate.py                  UART throughput diagnostic
  calibration/fit_calibration.py  intrinsic calibration model fitter
CLAUDE.md                         detailed build & architecture notes
```

Build outputs (`Debug/`, `Release/`) are generated by Code Composer Studio and
are git-ignored.

## Firmware

Built with the CCS-generated GNU makefiles. The TI MSP430 codegen toolchain is
expected at `C:/ti/ccs2050/ccs/tools/compiler/ti-cgt-msp430_21.6.1.LTS`
(`CG_TOOL_ROOT` in the makefiles).

```sh
gmake -C "CCS Project using GUI Composer/Debug" all      # or Release/
```

Two mutually-exclusive output modes (compile-time, in `Include/Config_Common.h`):

- **SPI slave** (`USE_SPI_OUTPUT`, default) — the production host interface.
- **UART stream** (`USE_UART_OUTPUT`) — text frames for bring-up and the host
  tools below (921600 8-N-1).

See [CLAUDE.md](CLAUDE.md) for the layered architecture (application / GUI
transport / HAL).

## SPI protocol (v2)

The master polls the sensor; each `READ_FRAME` returns a 27-byte frame (sun
unit-vector, raw quadrant ADCs, dark-corrected sum, on-chip temperature in
centi-°C, status flags, CRC-16/CCITT-FALSE). The full spec, a reference master
driver, and the master-side reliability requirements are in
[SUN_SENSOR_SPI_PROTOCOL.md](SUN_SENSOR_SPI_PROTOCOL.md).

## Host tools

```sh
pip install -r tools/requirements.txt
```

Recommended bring-up flow (UART build), decoupled so a visualizer crash can
never lock the serial port:

```sh
python tools/serial_log.py --port COM19 --out sensor.log   # owns the port
python tools/sun_sensor_viz.py --file sensor.log           # live 3D vector
```

### Calibration

`tools/calibration/fit_calibration.py` fits the per-sensor intrinsic map
(measured centroid → true gnomonic angles) from a **radial (Option-B) bench**
sweep, selects the polynomial degree by cross-validation, and exports trig-free
C coefficient tables for the firmware. Validate the machinery with no hardware:

```sh
python tools/calibration/fit_calibration.py --self-test
```
